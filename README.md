# sisumate-legal

Public legal/support pages for Sisu Mate, served via GitHub Pages. Each is a
full standalone page (not an iframe fragment) — paste these URLs directly
into App Store Connect / Play Console form fields, or embed via iframe on
the marketing site if preferred.

- Privacy policy: https://cadburies.github.io/sisumate-legal/privacy-policy.html
- Terms of use:    https://cadburies.github.io/sisumate-legal/terms.html
- Support:         https://cadburies.github.io/sisumate-legal/support.html

Source of truth for edits lives in the main SisuMate repo at `legal/` — copy
changes over from there rather than editing this repo directly, so the two
don't drift.
